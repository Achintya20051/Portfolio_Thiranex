# Personal Portfolio — Thiranex Internship Task

A simple responsive, multi-page portfolio built with semantic HTML5, CSS, and a small amount of JavaScript.

## Pages
- `index.html` — introduction and skills
- `projects.html` — project cards
- `contact.html` — accessible demo contact form

## Run locally
Open `index.html` in a browser. No installation or build step is required.

## Accessibility and SEO features
- Semantic landmarks and descriptive page titles
- `lang="en"`, viewport and meta description tags
- Skip-to-main-content link
- Visible keyboard focus indicators
- Native form labels, suitable input types, and required validation
- Responsive layout and reduced-motion preference support
